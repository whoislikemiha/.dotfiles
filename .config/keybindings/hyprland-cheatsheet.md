# Hyprland Keybindings Cheatsheet

Config: `~/.config/hypr/bindings.conf` (symlinked in this directory)

## Application Shortcuts

| Keybinding | Description |
|------------|-------------|
| `SUPER + Return` | Terminal (in current directory) |
| `SUPER + E` | File manager (Nautilus) |
| `SUPER + B` | Browser |
| `SUPER + SHIFT + B` | Browser (private mode) |
| `SUPER + S` | Spotify |
| `SUPER + N` | Editor |
| `SUPER + T` | Activity monitor (btop) |
| `SUPER + D` | Docker (lazydocker) |
| `SUPER + O` | Obsidian |
| `SUPER + /` | 1Password |
| `SUPER + A` | Claude AI |
| `SUPER + C` | VSCode |
| `SUPER + Y` | YouTube |
| `SUPER + G` | WhatsApp |
| `SUPER + X` | X (Twitter) |
| `SUPER + SHIFT + X` | X Compose |

## Window Management

| Keybinding | Description |
|------------|-------------|
| `SUPER + Q` | Close active window |
| `SUPER + F` | Toggle fullscreen |
